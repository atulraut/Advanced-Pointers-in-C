Basics of Pointers :
-----------------------------------------------------------------------

Pointer Syntax : int d = 10;
Declaration :
	    double *ptr;
Initialization :
	    ptr = &d;
Dereferencing:
	printf ("", *ptr);

Reference Operator - &   [ADR]
	  - [A]ddress of - Read as
	  - [D]irection operator - Also called
	  - [R]erence Operator
Dereference operator - * [VID]
	  - [V]alue at - Read as
	  - [I]ndirection operator
	  - [D]eference operator

Level of Indirection :
int *ptr   - level of indirection is 1.
int **ptr  - level of indirection is 2.
int ***ptr - level of indirection is 3.


A dangling pointer is a pointer that refers to an object whose
lifetime has ended or whose memory has been released.
Dereferencing it causes undefined behavior.
Ex -
    int *p = malloc(sizeof(int));
    *p = 100;
    free(p);
    printf("%d\n", *p);  // ❌ dangling pointer

lvalue error :

int a = 5;
int b = 7;

(a+b)++ <-- (12)++ <-- 12++ we cant do so lvalue error we get it here.

++a++ <-- Same error, associativity right to left, result is in tempory
location which doesnt have memory associated with gives us lvalue error.

Both ++ operators here are postfix/prefix increment operators, but their precedence is different:

Operator	Type	   	Precedence
a++		postfix ++	higher
++a		prefix ++	lower

So the compiler parses:
++a++ as: ++(a++)

not: (++a)++  <-- That's the important precedence point.

Precedence determines grouping between different operators;
Associativity resolves grouping when operators of the same precedence are adjacent.
